# Local Fonts Directory

Place custom `.woff2`, `.woff`, or `.ttf` handwriting font files in this directory.

Supported / Fallback styles configured:
1. **Classic** (`font-handwritingAlt` / Kalam Script or local serif-script)
2. **Casual** (`font-handwritingCasual` / Patrick Hand or local clean print)
3. **Cursive** (`font-handwriting` / Caveat or local fluid fountain-pen cursive)

If custom local font files are added here, `@font-face` declarations can directly map them to the corresponding style IDs.
